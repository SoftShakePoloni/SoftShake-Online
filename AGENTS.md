# UI and design workflow

- For work that creates or reshapes the customer or admin interface, read and follow `.agents/skills/frontend-design/SKILL.md` before writing UI code.
- After UI changes, review the affected files with `.agents/skills/web-design-guidelines/SKILL.md` and address relevant findings.
- Use the configured shadcn MCP when component documentation or registry examples would help. Inspect generated component code and adapt it to the project's existing tokens and patterns.
- Use the 21st.dev MCP for component discovery and generation when it is enabled and connected. Treat its output as a starting point and review it against this project's design and accessibility requirements.
